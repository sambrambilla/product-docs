# product-docs

Practical product management templates I use across my projects.

Built from 7+ years of UX and 4+ years of product management across B2B SaaS, consumer apps, and Web3 infrastructure.

---

## Templates

| File | What it's for |
|---|---|
| [`prd-template.md`](./prd-template.md) | Full product requirements document — from problem to launch plan |
| [`product-brief-template.md`](./product-brief-template.md) | Pre-PRD alignment doc — use before committing to a solution |
| [`naming-framework.md`](./naming-framework.md) | Step-by-step framework for naming products, features, and companies |

---

## Philosophy

- Brief before PRD. Align on the problem before designing the solution.
- Explicit scope kills scope creep. Always write what you're NOT building.
- Naming is strategy. A bad name creates a permanent positioning debt.
