# Product Naming Framework

> **Template version:** 1.0 · Maintained by [@sambrambilla](https://github.com/sambrambilla)  
> Adapted from the Moondrop naming methodology.

---

## Philosophy

A good product name is not clever — it's **accurate, memorable, and ownable**.  
It survives a pitch, a domain search, and a customer saying it out loud for the first time.

---

## Step 1 — Define the naming brief

Before generating candidates, answer these:

| Question | Answer |
|---|---|
| What does this product do in one verb? | |
| Who is the primary user? | |
| What feeling should the name evoke? | |
| What should it never sound like? | |
| What category is it in? (security / SaaS / consumer / infra) | |
| Hard constraints (length, language, must avoid) | |

---

## Step 2 — Generate candidates

Use at least 3 of these generative lenses:

| Lens | Description | Example |
|---|---|---|
| **Functional** | Name describes what it does | Zapier, Buffer |
| **Metaphorical** | Name borrows from another domain | Slack, Orbit |
| **Invented** | Portmanteau, modified spelling | Spotify, Figma |
| **Mythological / Lore** | Reference to myth, space, nature | Voidnaut, Argo |
| **Positional** | Name signals category leadership | Sentinel, Prime |
| **Abstract** | Evocative but not literal | Notion, Miro |

**Generate:** minimum 10 candidates per lens you use.

---

## Step 3 — Score candidates

Rate each name 1–5 across these axes:

| Criterion | Description |
|---|---|
| **Recall** | Can someone repeat it after hearing once? |
| **Spelling** | Is it spelled the way it sounds? |
| **Uniqueness** | Does it stand out in the category? |
| **Tone fit** | Does it match the product's personality? |
| **Scalability** | Does it still work when the product grows? |
| **Domain viability** | Is `.com`, `.app`, or `.io` available or acquirable? |
| **Trademark risk** | Does a quick search show conflicts? |

---

## Step 4 — Shortlist criteria

Advance names that:
- Score ≥ 3 in all axes
- Pass a "say it out loud" test with 3+ people outside the team
- Have a viable domain path
- Don't rhyme with or resemble a competitor

---

## Step 5 — Validate

- [ ] Google the name + your category
- [ ] Check [Namechk](https://namechk.com) for social handle availability
- [ ] Run a basic trademark search (USPTO / INPI for Brazil)
- [ ] Test with 3 people from the target audience — no context, just "what do you think this is?"

## Anti-patterns to avoid

- **Generic tech suffixes:** -ly, -ify, -io used without strong name behind it
- **Overused archetypes:** Nexus, Nova, Apex, Edge, Core, Forge — saturated
- **Literal descriptions:** sound like features, not products
- **Hard-to-spell invented words:** will kill word-of-mouth
- **Names that mean something bad in another language:** always check PT, ES, ZH, AR
